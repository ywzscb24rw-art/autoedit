## Answer key: what a good edit should do

**Clean edit** (should come out around 4–5 minutes):

| What's in the script | What should happen |
|---|---|
| "is this recording? ... Cool." | Cut (meta-talk) |
| 3-second silent start and the other `[pause]`s | Shortened to a beat |
| um / uh | Cut |
| "a, a unit converter", "the the best" | Stutter cut |
| "I use this, **like**, ten times a day" | Filler "like". It may or may not be cut, since it's context-dependent |
| "**I like** this one the most" | Must be kept. That "like" is a real word. |
| Coffee tangent | Cut |
| "you get... wait, no, let me redo that" | Cut, keeping the second take |
| "I, uh, I think the reason people..." followed by "let me say that better" | Cut the first take and keep "The reason nobody knows Command Backtick..." (this tests an announced retake) |
| "So the... the the best version" | The false start is trimmed |
| "I should have mentioned this back with Spotlight" | The AI may move it up to the Spotlight section. Either result is fine. |
| "I'll cut this part out later... where's the..." | Cut |

**Find clips** (set clip length to 30–90 s): good candidates are
1. The **hook plus Spotlight calculator** section ("Most people lose twenty minutes a day...")
2. **Command Backtick**, which has a story ("like an animal") and a payoff. This is probably the best clip.
3. **Screenshots with Control**, with "four hundred screenshots" as the payoff

Clips should **not** start with "Okay, shortcut number two..." or refer back to "the first one".
